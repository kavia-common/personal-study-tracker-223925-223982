# Database Container

This container is dedicated to running PostgreSQL only.

What this container does:
- Initializes and starts PostgreSQL on port 5000
- Creates database: myapp
- Creates user: appuser (password in scripts)
- Writes connection helper to db_connection.txt

What this container does NOT do:
- It does not start any Node.js servers. This prevents MODULE_NOT_FOUND errors during startup.

Optional: db_visualizer helper
- A simple Node-based viewer exists under Database/db_visualizer but is not part of this container's startup.
- To use it locally:
  1) cd Database/db_visualizer
  2) source postgres.env (generated by startup.sh after DB starts)
  3) npm install
  4) npm start
- This runs a viewer on port 3000 and connects to the local PostgreSQL exposed via port 5000.

Connection string
- See db_connection.txt for a ready-to-copy psql command.
